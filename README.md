# 我的房間 · 家具試擺

同時擺放兩款依規格 DM 重建的 MOCHI 沙發，搭配照片重建的胡桃木圓邊桌。原房東沙發、長方形茶幾、裝水手推車、電視前玻璃桌與白色除濕機已移除。

- 兩人座：192 × 99 × 77 cm；座深 66 cm、座高 44 cm。保留在窗邊原沙發位置，面向電視。
- 轉角單人：95 × 95 × 77 cm；座深 62 cm。放在柱子靠電視的一側，也就是原裝水手推車的位置，座位朝床。DM 未單列轉角座高，模型暫採同系列 44 cm。
- 軟包曲面採中央鼓起、周邊收緊的泡棉形狀；扶手呈長抱枕造型。
- 可切換照片色卡中的 10 種布料配色與織紋，旋轉查看房間及輸出畫面。
- 胡桃木圓邊桌小款：寬 50 × 深 50 × 高 50 cm，依 IMG_6220 尺寸牌製作，含圓弧桌緣、外撇桌腳與分叉支撐。
- 結構柱依 IMG_6227、IMG_6228、IMG_6229 修正：兩側同寬、同深、同一條橫向位置線，房東小桌子向衣櫥方向偏約 10 cm，右柱不再與桌子完全置中；上半白牆、下半灰磚。
- 衣櫥側面與柱側留約 30 cm 狹縫，距離依照片與使用者描述估計。
- 衣帽架放在柱子與出入口之間的凹位，柱邊到門框約 1 公尺；外形、距離與尺寸依照片估計。
- [三層木架](https://github.com/RolanthHuang/Wooden_3_tier_shelf) 沿用原專案的 27 根層板木條、邊框、螺絲與固定腳墊，放回照片中電視前、靠牆的位置。原專案比例約 48 × 43 × 96 cm，未經實量。
- 兩張沙發同時顯示，不提供款式切換或位置調整；布色一起變更。圓桌沿用原茶幾中心。

沙發外尺寸已由模型實際邊界核對；曲面、車縫與腳座依照片估計。房間未實測部分仍為照片估計，布色以實物色卡為準。圓桌外尺寸依尺寸牌，桌板厚度、桌腳截面與分叉細節依照片估計。

執行 `node scripts/verify-models.cjs` 可檢查兩款沙發外尺寸、座深、座高、扶手鼓起輪廓與圓桌外尺寸。

以 Three.js、TSL 與 WebGL2 製作的可互動房間模型，可旋轉、縮放及第一人稱走動。

**[直接進入 3D 房間 →](https://rolanthhuang.github.io/my_room/)**

## 操作

- 拖曳旋轉，滾輪縮放；右鍵拖曳平移。
- 按「走進房間」後，拖曳轉頭，使用 WASD、方向鍵或畫面方向按鈕移動。
- Esc 返回旋轉觀看；家具與牆面設有移動碰撞範圍。
- 可切換入口、窗邊及俯視位置，調整亮度與日光／暖光。
- 「輸出畫面」可產生目前的 3D 畫面 PNG。

## 面積試算

窗框至浴室門方向的 618 cm 已由使用者再次確認為實量，房寬 425 cm 仍為照片估計。

- 主房間矩形外框：4.25 × 6.18 = 26.265 m²，約 7.95 坪。
- 另外加入使用者估計的廁所 1 坪：合計約 8.95 坪。
- 扣除兩根柱子約 0.12 坪後，連同廁所粗估約 8.83 坪。

目前模型已達使用者提出的至少 8.1～8.3 坪。坪數無法單獨證明柱子至浴室牆的比例；總長沿用已確認的 618 cm，房寬與柱位仍需實量校正。

## 本機觀看與修改

`index.html` 已將程式和程序產生的材質打包在同一個檔案，執行時不依賴外部 CDN。

使用本機預覽伺服器：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

然後開啟 `http://127.0.0.1:8080/`。

修改來源後重新打包：

```sh
npm ci --ignore-scripts
npm run build
```

來源位於 `src/room.js`、`src/walnut-table.js`、`src/sofas.js`、`src/sofa-layout.js`、`src/room-fixtures.js`、`src/wooden-shelf.js` 與 `src/template.html`，套件版本已固定。模型以公尺為單位。

## 渲染與授權

使用 Three.js 0.180.0 的 `WebGPURenderer({ forceWebGL: true })` 與 TSL node materials，實際渲染後端為 WebGL2。

Three.js 的 MIT 授權保存在 [licenses/three-MIT.txt](licenses/three-MIT.txt)，也包含於打包檔案中。
